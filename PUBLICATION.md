# Release Information

The project is an experimental developer runtime. It is not yet an installable
operating system or a production support offering.

## Scope

The [license scope](LICENSE-SCOPE.md) identifies the software, documentation,
third-party dependencies and artwork terms. Each component retains its applicable
license. No model weights or proprietary LOGFORCE engine are included in the
community source distribution.

## Verification

See the [development guide](docs/development.md) for build and test commands and
the [ONNX worker report](docs/onnx-worker.md) for the implemented inference profile
and its limitations. The [roadmap](docs/roadmap.md) separates current capabilities
from planned runtime and OS releases.

Community use does not establish a paid-service contract or support SLA. See the
[community terms](TERMS.md).
